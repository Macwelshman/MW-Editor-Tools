Authorised 2026-10-13. Stage 1 one-step Undo, shortcut and validated prop restore paths are retained. No Redo/history work or computer use. In-game acceptance remains a grouped user task.

IMPLEMENTED: the bound area/surface capture path no longer requires an area-only asset. A single standard surface or walking-space area directly owned by the writable edited asset can be captured in Sub-elements or Everything mode. The original polygon/flags/local-node/parent-mesh/container capture, final ObjectSubAreas recreation/rebinding and native deferred regeneration path remain in use. Owner transform must stay unchanged. Pending native edits refuse capture.

Mixed companions are now captured and validated, rather than bypassing the former restriction:

- Props: direct owner buffer, bounded typed prop/nested-group snapshots, unique placements, full existing transform/seed/colour/local-cache/elevation/street-light/reference checks. Up to 128 direct prop roots with the existing per-tree limits; descriptor/placed-root counts must agree. The area action must preserve all props. Undo reuses existing preflight/seed-restoration/final validation for rebuilt companion groups.
- Effects: edited effect containers, prefab identities, transform, scale, intensity, animation group, parent-mesh/local transform and elevation. Only detached cache indices are normalized. Descriptor/placed counts must agree; duplicate ambiguous placements refuse capture.
- Networks/lanes: a closed owned companion graph (up to 1024 entities, 8192 links/connections, 2048 connections per entity). Captures node geometry/rotation, edges/endpoints, curves/lengths/local curves, lane paths, subnetwork/sublane memberships and path methods, connected edges, container parameters, prefab identities and available seeds. Matching remaps fresh entity IDs by unique semantic geometry and then verifies ownership/topology/path bits. Seed restoration writes only after the entire companion graph preflight succeeds. Changes beyond seed differences refuse restoration.
- Surviving original entities must remain inside the mapped graph. This includes areas, props, effects and networks; a surviving orphan outside the owner graph prevents completion. The deleted area must be gone before an Undo slot is recorded. Capture settles for three frames; restore must pass native finalization and three stable validation frames before consuming the slot. Transient missing graph data waits within the existing 120-frame bound.

Every non-area prefab payload/component identity/active state must remain unchanged by native deletion. External captured prefab definitions are checked through the existing snapshot/reference policy. Snapshot weights now include companion graphs and reference images. The new deletion attempt still clears the previous slot; unsupported or failed capture cannot expose an old Undo action. Companion images are detached values; no entity IDs are resurrected and no referenced prefab is written.

## Add to the grouped in-game acceptance batch

1. Load a disposable saved mixed fixture with props, a network, a lane, effects and at least two bound areas/surfaces. Select the owning asset in Workspace; recovery enabled, no Enable/Arm step.
2. Everything- or Sub-elements-delete one surface, then use the configured Undo shortcut (default Ctrl+Z). Check polygon, elevation, parent meshes, settings and original placement.
3. Check every companion remains unchanged: prop positions/colours, network/lane curves and connections, effect settings and placements. Repeat on a walking area.
4. Test the last remaining area so ObjectSubAreas is recreated in its original slot. A successful Undo must consume the one slot; no Redo is required.
5. Save the restored disposable result under a new name and reopen; verify geometry, settings and companions. Do not overwrite the baseline. Group the existing Stage 1 checks into the same pass.

Boundaries: standard direct-owned surface/space polygons only, up to 128 areas/4096 vertices, no lots, nested area ownership, standalone areas, activity-location/stamp owners, ambiguous companion mappings, unsupported prop schemas/attachments or external network connections. Generated graphs outside the explicit budgets/schema refuse capture. This stage preserves network/lane/effect companions; it does not implement deleting those elements as Undo targets. Those are subsequent stages.
