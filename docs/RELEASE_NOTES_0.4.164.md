# Release notes — 0.4.164

- Replaces the launcher with the supplied MW Editor Tools coloured diamond logo, with transparent corners.
- Positions the icon in the top-left launcher row beside the editor sidebar. It shifts right around occupied positions, follows sidebar/UI resizing, and reclaims free space when other icons disappear.
- Keeps the icon visible while the window is open. Click it again to close the window.

The supported editing and Undo scope is unchanged from [0.4.163](RELEASE_NOTES_0.4.163.md). No new in-game acceptance run is claimed for this interface update.

With Cities: Skylines II fully closed, run **MWEditorTools-0.4.164-Setup.exe**. The unsigned Windows installer requires .NET Framework 4.8, backs up the existing mod folder and verifies installed files. A manual ZIP and SHA256SUMS.txt are also supplied. The repository remains private.
