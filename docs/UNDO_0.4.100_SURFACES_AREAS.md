# Undo 0.4.100 — bound and unbound surfaces and areas

VERIFIED-STATIC implementation: standalone SurfacePrefab and SpacePrefab instances now use automatic bulldozer Undo, alongside existing bound surface/space recovery. One deletion is retained; no redo/history work added. Bound targets use Sub-elements or Everything. Unbound targets use Main-elements or Everything. Ctrl+Z dispatches both through the existing deferred shortcut.

Standalone capture keeps detached node positions/elevations, AreaFlags, optional LocalNodeCache positions/parent meshes, surface expansion buffer offsets, native prefab identity, optional editor-container prefab/scale/intensity/group and optional random seed. Geometry/cache/expansion budgets are 4096 entries, references 250000 snapshot units. Nonfinite data, unknown ECS schemas, multiple targets, missing triangulation and unsupported prefab types refuse capture with a reason. Existing bound companion ownership/geometry/reference guards remain active.

Capture requires native Apply acceptance and confirmed disappearance of the original entity. Undo resolves current prefab entities, creates a fresh entity from AreaData.m_Archetype, restores typed data and marks Applied/Created/Updated. Triangles and Geometry are regenerated by native systems. Success requires the original still absent, references unchanged, triangulation present and exact captured values across three consecutive frames. Native denial/exceptions clear capture; subsequent deletion attempts replace the prior slot. Editor/context invalidation and Forget clear the slot. Failed or cancelled asynchronous restoration requests native deletion of the new entity; native cancellation completion remains UNPROVEN.
