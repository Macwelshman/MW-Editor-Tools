# Evidence guide

Generated through read-only Colossal.Mono.Cecil metadata/IL inspection of the installed assemblies. These are selected diagnostic extracts, not C# source or runtime traces. Extraction helpers remain in the chat's work directory. Installed assemblies are not included.

- environment.txt: path, initial SDK result and exact-build identity.
- managed-inventory.csv: available managed assemblies.
- inspection.txt: initial relevant method IL, header delegate assignment/callers, prefab operations and recursive type-name history search.
- detail.txt: ApplyPrefabsSystem synchronisation, bulldozer definition job, native AppBindings dialogs, EditorGenerator adapters and prefab storage metadata.
- paths.txt: PagedList/ListAdapter removal, dependency collector, cleanup and bounded history method scans across four assemblies.
- finaltrace.txt: Area/Net/Object deferred deletion methods and ArrayAdapter deletion.

Use method headings and IL offsets for stable references. File line numbers are incidental. `Undo|Redo` substring scans also produce false positives such as Underground and endangered; these are not undo findings. Native undo absence is not established by this bounded search.

Game assembly SHA-256 was rechecked after setup and matched the initial inspection. No live editor operation was tested.
