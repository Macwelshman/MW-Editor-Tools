## Implemented scope

- Components: Choose fields to copy reveals supported top-level fields for checked components, with All fields, No fields and a UI Object Group and Priority preset. Existing Copy/Copy All, token checks, paste modes and Restore remain. Copy choices are tied to the source selection revision. General public settings snapshots now project fields and merge them into destination snapshots rather than replacing the whole image. Typed field adapters also honour the mask. Opaque/private/native/cyclic settings remain outside supported copying.
- UI Object m_Icon is excluded at the backend from every component clipboard, even an explicitly requested Icon-only selection. Existing destination icons survive replacement. Native defaults, including any icon/group chosen by AddComponent, survive unselected fields on additions. Source assets/referenced prefab identities remain unchanged.
- Priority numbering: explicit full workspace scan, selection/filter, start and positive increment. Default naming parser matches SR ResidentialLow S01_L1 2x2 and orders numeric S, L, width and depth, assigning a separate priority to every chosen asset. Optional named-group pattern supports other naming formats. Unmatched/duplicate names, read-only/missing UI Object targets, stale workspace/identity/settings/name, oversized inputs and integer overflow refuse. Preview is read-only; changing choices/inputs requires a new preview. Apply revalidates the captured preview and supports guarded Restore. Only m_Priority is written. Does not scan ImportedData, modify subscribed files, create components or save assets automatically.
- Localisation: independent name and description clipboards containing detached, nonblank language/text entries (matching native ValidEntries filtering). Destination-only languages are retained, matching source languages are merged for the chosen field, the other field/internal prefab name/icon remain unchanged. Uses native inspector WIP fields; no direct locale-file writing. Save normally or use Multi-Save to persist translations. One guarded Restore; read-only/stale target/fields/later translation edits refuse. Locale text clipboards are separate from component and element clipboards.
- Explicit Components button commands use dialog/application/heartbeat/save/recovery guards without the keyboard-only typing block, so Preview/Apply can follow numeric input. Keyboard shortcut typing protection remains.
- Header focus: a single native AutoNavigationScope now groups the header's Undo/Close buttons beneath PanelHeader. Regression model reproduces the original second-key registration failure and verifies grouped registration plus exact-key cleanup.
