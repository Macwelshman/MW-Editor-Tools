# Undo 0.4.115 — built-in prop move Undo

Scope: user explicitly authorised implementation on 2026-10-15, using the built-in move/relocate tool. Implements one completed move of a supported standalone prop or directly bound prop/group, including foliage and captured nested children. Uses the same Ctrl+Z and single last-action slot as deletion recovery. No Redo/history expansion. Areas, networks, buildings/service upgrades, moving an independently nested child inside another placed prop, inspector-field edits, scale and third-party move tools remain outside this stage. Existing 0.4.114 fence/network deletion acceptance is preserved as a regression baseline.

VERIFIED-STATIC: ObjectToolSystem.StartMoving captures typed original placement before native previews. Move Apply is guarded separately from placement; its own GetAllowApply callback and final ApplyMode.Apply must both confirm acceptance with a matching native m_MovingObject before observation begins. The Boolean native Apply argument is supplied from input WasReleasedThisFrame in OnUpdate (e.g. IL_045b-0465); grouping uses accepted native commits rather than assuming every Apply call commits. Preview/cancellation retain the previous slot and block Undo commands while previewing. Unsupported completed moves/placements clear stale slots. A supported no-op preserves the slot. A changed move replaces it only after stable native/source checks. New deletions and supported list edits invalidate moves through the existing shared context path.

Standalone capture reuses the supported typed prop/foliage tree schema. Forward validation requires unchanged owner, prefab identities, tree shape, rigid child/effect poses and stable local child attachments. After-state must remain exact before Undo. Restore writes captured positions/rotations and supported typed values on the original group, marks native Updated/BatchesUpdated and verifies the complete before-image over three stable frames. Effect entities are addressed through the current after-state, not stale before IDs. Original entity replacement, reparenting, missing/unsupported schemas and non-rigid edits are refused rather than guessed.

Bound capture also records the writable owner source, complete retained prop forest, areas, effects, closed network graph and external references. Retained companions must remain unchanged before the move is recorded. Only proved ancillary saved representations can normalize; the original prop source list stays in its before-image. Undo reuses the validated native parent-asset regeneration, typed prop restoration, finite network cache/seed repair and bounded world-rounding validation from 0.4.114. Source, ownership, connections and all companions must validate before consuming the move slot. The shared native restoration path selects the move slot explicitly, leaving deletion slot semantics intact.

Move hook attachment is optional and conflict-checked. Partial move hooks are removed on failure while existing deletion patches stay installed. Loaded-world/asset changes, dialogs, saving, unsupported targets, concurrent native recovery and interruptions are guarded. Capture/restore expires at 120 frames. Deferred scene rollback remains UNPROVEN; incomplete restoration stops recovery and asks for reload without saving.
