# Undo 0.4.109 — bound lanes and networks

VERIFIED-STATIC: implements automatic last-deletion Ctrl+Z recovery for one directly bound editable lane or network edge in Sub-elements/Everything mode. It shares the single-deletion workflow, clears older slots on every new bulldozer attempt, preserves the native denied-Apply behavior and blocks another bulldozer Apply while capture/restoration is pending. No Redo/history expansion.

Capture records both network/lane source lists, full closed owned topology, node/edge curves, local curves when present, seeds, path-node owner bits, sublanes/path methods, container identities/parameters, and retained props, areas and effects. The target must be a directly owned source segment. Root lists must agree with native source prefab counts. Open/external or ambiguous graphs, multiple targets, standalone networks, junction-only deletion, generated traffic-lane deletion, custom network list subclasses and nonstandard editor containers are refused.

Before a record is exposed, the target must be physically gone and every retained entity must remain the same with unchanged captured data/topology. Only the target, its generated descendants and newly orphaned endpoints may disappear. Exactly one selected source row must be removed. Curves/node indices may normalize in saved descriptors only with mandatory complete live graph equivalence. Ancillary source representations can be adopted only after full retained graph equality across three stable frames; the deleted source list stays unchanged in the before-image.

Undo prepares detached data first, reinstates any removed list components in their original positions (including either lane/network component order), rebinds before/after field owners, applies the source and invokes the native PrefabSystem regeneration path. Retained props use the existing typed restoration/preflight path; network seeds are restored only after topology maps. Full source, topology, references, companions and surviving source containment must validate over three stable frames before the slot is consumed. Capture/restoration expires at 120 frames. Source rollback is attempted on synchronous failure; deferred scene rollback remains UNPROVEN and failure asks for a reload without saving.
